# Playtest M1 — инструкция для оператора

## Что это за майлстоун

Vertical Slice Core: луп целиком. Подъём/спуск по switchback-подъезду,
6 аномалий, отложенный вердикт (трафарет этажа на следующей площадке),
reset с «перемоткой», временный процедурный звук, полный контроллер
(head bob с шагами в такт, landing dip, sway от Tension, спринт со стаминой
и дыханием). Цель прохождения: **этаж 9**.

## Запуск

- Сборка: `etazh9.exe` (debug, F3 работает) — или редактор: F5.
- Управление: WASD — ходьба, **Shift — спринт** (стамина звуком, без полосок),
  мышь/стики — обзор, Esc — отпустить мышь, F3 — диагностика
  (этаж/seed/Tension/текущая аномалия Q).
- Фиксированный seed для воспроизводимости: переменная окружения
  `ETAZH9_SEED=42` (любое число ≠ 0). Один seed = одна последовательность
  аномалий.

## Правило игры (тебе можно, незнакомцу — нельзя рассказывать)

Заметил странность на площадке или марше выше — иди ВНИЗ. Всё чисто — ВВЕРХ.
Трафарет этажа открывается только на СЛЕДУЮЩЕЙ площадке. Ошибка = перемотка
на 1-й этаж.

## Содержимое (6 аномалий, по одной на категорию)

A1 лишняя пара обуви у двери (OBJECT) · B1 тринадцать ступеней (SPATIAL) ·
C1 тёплая лампа (LIGHT) · D1 граффити «НЕ ПОДНИМАЙСЯ» вместо «ЦОЙ ЖИВ» (TEXT) ·
E3 мокрые следы вниз по ступеням (ENTITY) · F2 субтитр без звука (META —
сравни со штатными «[хлопок двери наверху]», которые звучат).

## Чек-лист DoD (BRIEF: «незнакомец понимает правило без слов»)

- [ ] 60 fps держится (F3, debug-сборка)
- [ ] Дай поиграть кому-то, кто правила НЕ знает: за 10 минут человек
      формулирует правило сам и хотя бы раз поёжился
- [ ] Подъём 1→9 проходится; финальная карточка «ЭТАЖ 9», Enter — заново
- [ ] Шаги звучат в такт покачиванию камеры; спринт «дышит» при усталости
- [ ] Сброс: перемотка, этаж 1, трафарет «1»
- [ ] Каждая из 6 аномалий хоть раз встретилась и читается (несколько забегов
      или сиды)

## Известные ограничения M1 (намеренные)

- Глитч-вспышка на КАЖДОЙ площадке — это механика (маскирует перестройку мира)
  и стилистика VHS; в M3 станет шейдерным tracking-глитчем.
- Все звуки — процедурные PLACEHOLDER_ (настоящие файлы — M4 по манифесту).
- Концовка — карточка-заглушка (настоящая сцена «Дом» — M2/M4).
- Визуал — греябокс: PS1/VHS-стек, туман и текстуры — M3.
- Меню/паузы нет (Esc отпускает мышь), яркость не калибруется — M3.
- Окна подъезда чередуют стороны шахты (D-008) — упрощение греябокса.

Фидбек по ощущению лупа (длина марша, частота аномалий ~45%, скорость ходьбы)
особенно ценен сейчас — до M2-тюнинга Director'а.
