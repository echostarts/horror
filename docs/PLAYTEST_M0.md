# Playtest M0 — инструкция для оператора

> Рендер проекта — OpenGL Compatibility (D-006): в консоли debug-сборки
> должна быть строка «OpenGL API … Compatibility». Если видишь «Vulkan …» —
> запущена старая сборка.

## Запуск в редакторе (быстрая проверка)

1. Godot **4.4.x stable** → Import → выбери `project.godot`.
2. Первый импорт создаст `.godot/` и `*.uid` — это нормально. Если Godot
   сгенерировал новые `.uid`-файлы — закоммить их.
3. **F5** (играет `scenes/main.tscn`).

## Управление

| Действие | Клава/мышь | Геймпад |
|---|---|---|
| Ходьба | WASD / стрелки | левый стик |
| Обзор | мышь | правый стик |
| Отпустить/захватить мышь | Esc | Start |
| Debug-оверлей (FPS, seed, Tension) | F3 | — |

## Windows-сборка (это и есть DoD M0)

1. Editor → Project → Export → preset **«Windows Desktop»** (уже настроен).
2. Если попросит export templates: Manage Export Templates → Download and Install.
3. Экспортируй с галочкой **«Export With Debug»** — в debug-сборке работает
   F3 для замера FPS (release-сборка оверлей не содержит, D-003).
4. Путь: `exports/etazh9.exe` (папка в .gitignore, в репо не попадёт).

## Чек-лист DoD

- [ ] Стабильные **60 fps** на твоём железе (F3 в debug-сборке)
- [ ] Подъём и спуск по пролёту без застреваний (ступени сглажены рампой —
      честное сглаживание придёт в M1)
- [ ] Обзор мышью плавный; чувствительность ок (пока меняется только в
      `user://settings.cfg`: `%APPDATA%\Godot\app_userdata\ЭТАЖ 9\settings.cfg`,
      ключ `[input] mouse_sensitivity`)
- [ ] Ресайз окна: картинка остаётся «жирно-пиксельной», по бокам леттербокс
- [ ] Геймпад: стики работают из коробки
- [ ] `settings.cfg` создаётся после изменения любой настройки

## Известные ограничения M0 (намеренные)

- Один статичный пролёт; лупа, аномалий и вердиктов нет — это M1.
- Нет head bob, звука шагов, меню, паузы (Esc просто отпускает мышь).
- Освещение простое, тумана/VHS-стека нет — визуальный пас это M3.
- Двери — декорации.

Если что-то из чек-листа не сходится — напиши в следующей сессии, чиню до M1.
